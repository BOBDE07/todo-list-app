# Todo List App

A modern and responsive Todo List application built using React and Vite.  
This project allows users to manage daily tasks efficiently with a clean UI.

---

## Live Demo

https://todo-list-app-three-jade.vercel.app/

---

## Features

- Add new tasks
- Delete tasks
- Mark tasks as completed
- Real-time UI updates
- Fast performance using Vite
- Clean and responsive design

---

## 🛠️ Tech Stack

- React.js
- Vite
- JavaScript (ES6+)
- CSS / Tailwind CSS (if used)
